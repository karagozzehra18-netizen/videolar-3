# Kâğıt kesik ışık kutusu  (`kagit-isik-kutusu`)

| | |
|---|---|
| Aile | Kâğıt ve kukla |
| Korku uyumu | ★★★ |
| İlk kare/parlaklık riski | orta (arka katman parlak tutulur) |
| Motor | yazılmadı |
| Kaynak teknik (animation-styles) | `25 paper-pop-up → toon-and-paper/paper.tsx` (`.claude/skills/animation-styles/src/styles/`) |
| Kaynak teknik (lemo-opuscar) | `paper-lantern/STYLE.md` (`~/lemo-opuscar/styles/`) |

## Palet
arka katman açık (#F0C890 alacakaranlık ya da #DFE6EE kış), ön katman koyu; sıcak ışık #FFD080
Marka renkleri yalnız üst bant, altyazı vurgusu, filigran ve bitiş ekranında (bkz. `kanal-kimligi`).

## Doku
kâğıt lifi, katman üstü ışık kenarı, katman altı koyu bant

## Çizgi
kesik kenar

## Hareket
katmanlar kayar/döner; ışık ipuçları
Adım: **akıcı (her kare)** · sürekli hafif kamera kayması · en az 3 derinlik katmanı (ön/orta/arka, paralaks).

## Geçiş
ön katman perdesi kapanır, ışık söner-yanar

## Ses tarifi
kâğıt hışırtısı, düğme tıkırtısı, müzik kutusu (çok kısık)
Kanal kuralı: 5-8 gerçekçi efekt, komik ses yok, müzik çok kısık (bkz. `ses`).

## Yapma
- açık ön katman (derinliği öldürür)
- belirli lamba tasarımı
- Marka/logo/gerçek kişi; ekranda gereksiz yazı; boş köşe; karanlık ilk kare.
